## 项目方向调整与开发进展

由于 LocationSpoofer 存在合规风险，并出现了一些偏离开发测试初衷的滥用情况，我们此前对项目进行了归档。

为了降低安全风险，同时继续方便开发者测试自己的软件，我们决定调整项目方向：**开发一款面向开发者的 Android 模拟器，在可控的测试环境中提供定位、路线及设备环境模拟能力。**

新工具将通过我们维护的 Android 系统实现相关功能，服务于自有应用或已获得明确授权的开发与调试场景，不针对第三方软件进行破解或反作弊绕过。

### 适配平台

- **macOS（Apple Silicon，M 系列芯片）**：当前主要开发与验证平台，采用原生客户端。
- **Windows（Intel / AMD x86_64）**：计划适配，相关系统与 ARM64 应用兼容方案正在推进，客户端及 Windows 环境仍需验证。
- Intel Mac、Linux 桌面客户端暂未确定发布计划。

各平台的实际开放时间以发布公告为准，不保证首个版本同时上线。

### 主要功能

新工具基于 Android 17 开发，已实现或正在完善的功能包括：

- **应用调试**：APK 安装与启动、自动识别包名、Logcat 日志查看、按应用筛选和搜索。
- **位置与路线模拟**：指定位置、路线编辑、GPX 导入及路线回放。
- **设备环境模拟**：传感器、网络带宽与延迟、Wi-Fi、蓝牙 BLE 和 NFC 测试。
- **自定义机型**：配置型号、品牌、序列号、IMEI、分辨率及其他测试参数。
- **指纹认证调试**：虚拟指纹，以及 macOS Touch ID 与 Android 测试认证流程的桥接。
- **测试场景管理**：保存、导入、导出和重复执行测试场景。
- **账号与会员服务**：账号登录、会员授权及高级测试模块的在线加载。

部分功能依赖配套系统、宿主平台或有效会员，具体范围以发布版本说明为准。模拟能力用于开发测试，不等同于真实手机硬件；Touch ID 桥接及软件安全仿真也不代表 Android 获得了真实硬件 TEE 或 StrongBox 能力。

## 项目说明

本项目历史版本包含定位数据模拟、路线回放、无线环境数据采集及传感器数据模拟等实现，部分功能涉及 Root 权限与 LSPosed／Xposed 系统接口 Hook。

这些能力可用于自有应用或已获得明确授权的测试环境，例如：

- 定位与坐标转换测试。
- 路线回放及应用兼容性验证。
- 无线环境与传感器接口测试。
- Android 系统接口与跨进程通信研究。

模拟数据不代表设备的真实位置、真实运动状态或真实无线环境，不应作为实际到场、运动成绩、考勤或其他真实性证明。
