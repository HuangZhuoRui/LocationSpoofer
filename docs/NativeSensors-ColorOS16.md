# ColorOS 16 原生传感器独立测试版

本文件描述 `LocationSpoofer-ColorOS-sensors-review` 的可选传感器实现；定位适配 PR 的范围见 `ColorOS16.md`。传感器改动尚未提交或推送。

## 行为与兼容范围

- `native_sensor_enabled` 默认关闭。开启并运行步数模拟、速度大于 0.1 m/s、调用方符合目标规则时，修改加速度事件并主动合成标准计步事件。
- `location_accel` 只处理加速度；`location_steps` 处理非唤醒型 `TYPE_STEP_COUNTER`、`TYPE_STEP_DETECTOR`。唤醒型、直接通道和厂商私有传感器没有适配。
- 两者使用 `SystemMotionGait` 的共享步相位，波形文件 `motion_gait.h` 未修改。相位按单调时钟增量累计；步频调整不重算过去的步数，暂停、会话切换或长时间停顿不补发旧步数。
- 每个实际合成步点生成的 Counter 与 Detector 使用相同时间戳；订阅或恢复时可以单独报告一次当前 Counter。系统缓存和批处理可能使应用收到回调的时刻不同。
- 暂停后恢复保留当前连接已合成的累计值。完全停用、连接销毁或进程重启后恢复硬件语义；不承诺模拟累计值与真实硬件计数在切换时连续。
- 只为系统已成功授权的订阅合成事件，通过原来的 `sendEvents` 保留订阅过滤、AppOps、首次 flush、隐私和背压处理。提交成功并不保证应用已经收到事件。
- 开关关闭后停止合成并放行硬件事件。模块关闭会串行停止更新并撤销 Hook；仍在系统内执行的旧注册不能恢复模块状态。撤销失败保留句柄，不叠加安装。

目标是 ColorOS 16 / Android API 36 / arm64。代码不检查机型、固件版本或 SHA-256，不使用固件函数地址、UID 字段偏移或导入表固定偏移。运行时按完整 C++ ABI 符号查找连接构造、销毁、注册、派发及 RefBase 引用接口；缺少必要接口时停用。

连接 UID 来自构造参数。异步派发通过弱引用提升取得临时强引用；RefBase 虚基类位置来自 arm64 Itanium ABI 的虚表元数据，仍要求符合该类的继承布局。这是接口与 ABI 兼容范围，不能等同于所有 ColorOS 16 固件已验证。首次开启前已存在、未捕获 UID 的连接会放行，测试时应重新打开目标应用。

两个原生库统一使用 ShadowHook 2.0.1 的 multi 模式维护 Hook 链，不与 LSPosed 的原生 Hook 引擎交叉安装。APK 必须包含 `libshadowhook.so` 和其初始化辅助库 `libshadowhook_nothing.so`。

## 2026-09-26 验证记录

- 87 项 JVM 测试通过，0 失败、0 错误。
- 全局与非全局版本、arm64-v8a 与 armeabi-v7a APK 构建通过；32 位仅验证构建，原生后端不会启用。
- PJX110 / ColorOS 16 上运行三组独立 NDK 回归程序通过：UID 生命周期和输入隔离；累计值 `100→102→103`、配对时间戳、重复步点拒绝、目标隔离、元数据保留、注册拒绝、停止同步、卸载竞态、卸载后旧 tick、死亡连接；真实 ShadowHook 双 Hook 任意顺序撤销及重装。
- 上述原生逻辑测试使用模拟的系统连接；Hook 链测试作用于独立测试程序中的函数。它们不等于 system_server 的端到端验证。
- 测试包已保留数据覆盖安装并能启动。重启后在实际 SensorService 中用独立探针验证：120、165、190 SPM 分别测得约 119.9983、165.0049、189.9914 SPM（排除注册初期硬件缓存事件）；Counter / Detector 时间戳配对，累计值递增。
- 同一探针连接暂停后恢复，累计值不倒退；暂停及关闭原生开关后，等待配置传播的稳定窗口内未收到步进事件。加速度在开启时返回模拟波形，关闭后恢复硬件数据。系统服务进程在测试期间未重启，测试配置已恢复为用户原配置。
- 8 个必需的 SensorService / RefBase 符号也在参考设备上实际解析成功。上述验证不覆盖其他 ColorOS 16 机型、长期运行、所有权限和系统压力场景。

NDK 回归程序位于 `xposed/src/test/cpp`。用 Android NDK 的 arm64 C++17 编译器、ShadowHook 头文件、`-static-libstdc++`、`-llog -ldl` 编译并链接 `libshadowhook.so`。推送程序及上述两个 ShadowHook 库，在手机独立临时目录设置 `LD_LIBRARY_PATH` 后运行，无需修改系统服务。

## 独立评审分支（2026-09-26）

本分支基于 `fix/coloros16-review-ready`，仅在基础适配之上增加原生实现、默认关闭开关、构建依赖与测试。基础分支无需 NDK/CMake/ShadowHook，传感器功能不再混入基础 PR。两分支均不包含本机绝对路径的 sensor-probe 构建引用。上文真机结果为拆分前同一传感器实现的历史结果；拆分后的 APK 尚未重启验证。
