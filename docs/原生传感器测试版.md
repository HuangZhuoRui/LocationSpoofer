# 原生传感器独立测试版

此目录是在 ColorOS 16 main 适配之上的独立实验实现，不应与适配 PR 一起提交。

- 系统应用管理页新增“原生传感器模拟（实验性）”，配置键 `native_sensor_enabled`，默认关闭。
- 关闭时不加载原生库；曾开启后再关闭会停止替换传感器数据，原生 Hook 保留透传，模块卸载时尝试撤销。
- 用户开启该开关、步频模拟并开始移动模拟后，才启用目标 UID 的加速度和计步数据处理。开启后需重启目标应用，让传感器连接被重新创建。
- 仅限 Android API 36、arm64；按原生符号解析及构造函数记录 UID，无固件固定偏移或哈希绑定。符号不兼容时不启用。
- 新增 NDK 27.2.12479018、CMake 3.22.1 与 ShadowHook 2.0.1 构建依赖，需单独评审。

拆分前完整版本已完成重启后的 120/165/190 SPM、暂停恢复和开关关闭实测，详见 [传感器验证记录](NativeSensors-ColorOS16.md)。当前独立分支 APK 的重启复验及运动世界路线启动仍待验证。

原生隔离测试在手机执行通过：UID 生命周期、多用户 UID、仅目标应用替换、输入缓冲区隔离、连接地址复用。此测试不代表真实 SensorService 运行或运动应用已通过。
